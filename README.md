# 💰 Compound Interest Calculator (Python CLI)

A simple command-line based Compound Interest Calculator built using Python.  
This program calculates the final balance based on user input for principal, interest rate, and time.

---

# ✨ Features

- 📥 User input for:
  - Principal amount
  - Interest rate
  - Time (in years)
- ⚠️ Input validation (no negative values allowed)
- 📊 Accurate compound interest calculation
- 🖥️ Clean terminal output

---

# 🧮 Formula Used

Compound Interest Formula:

A = P (1 + r/100)^t

Where:
- **P** = Principal amount  
- **r** = Interest rate  
- **t** = Time (years)  
- **A** = Final amount
